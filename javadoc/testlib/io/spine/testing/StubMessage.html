Class StubMessage

  • All Implemented Interfaces:
    com.google.protobuf.Message , com.google.protobuf.MessageLite , com.google.protobuf.MessageLiteOrBuilder , com.google.protobuf.MessageOrBuilder 
    
public abstract class StubMessage
 implements Message

    An abstract base for stub classes implementing the Message interface.

    Sometimes in tests it is not possible or inconvenient to have a real class generated after a Protobuf type. Such tests create stub classes implementing Message.

    The problem with this approach is that it such stub classes are quite big, while doing almost nothing returning null in most of the methods that need to return something.

    This class helps to "cut" most of such code in the derived classes.
